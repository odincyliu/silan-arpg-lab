# 比例校準

## 單一世界比例

Ryzom 原始環境網格及世界座標 **1.0 → Godot 1.0**，1 單位約 1 公尺。沒有對整個世界做 0.01／10 倍放大或縮小。

原始 Ryzom 為 Z-up；Blender GLB exporter 轉成 Y-up。世界位置公式：

```
Godot X = Ryzom X - 10304
Godot Y = 原始垂直高度（若存在）
Godot Z = -(Ryzom Y + 11725)
```

原點是 Silan 起始 NPC／出生點附近；本版實際出生點在村莊廣場 `(-5, 1.5, 40)`，重力落到地面。

## 動作及鏡頭校準

走路 2.5 m/s、跑步 5 m/s、衝刺 8 m/s。相機初始距離 20 m、俯角 45°、FOV 52°，滾輪距離 9–45 m。技能 1.6 m／4 m 是方便比較空間的暫時尺度。

`mesh_conversion_manifest.json` 保存各資產轉换前的尺寸。`acceptance_verbose.log` 包含腳底落地、緩坡貼地與三種速度的實際測試。
